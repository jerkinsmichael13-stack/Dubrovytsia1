# Сторінка «Воробин, 1918» (worobin-1918.html)

Сторінку збирає `build.py` з файлів у цій папці. Редагувати треба тут, а не готовий `worobin-1918.html`.

```
python3 tools/povstantsi/build.py   # реєстр учасників + список для розділу «Люди»
python3 tools/worobin/build.py      # сторінка «Воробин»
python3 build_index.py              # пошук по сайту
```

`python3 tools/worobin/build.py --check` — лише порівняти з поточним файлом, нічого не записуючи.

| Файл | Що в ньому |
|---|---|
| `shell.html` | оболонка: head, шапка, футер; мітки `@@CSS@@`, `@@JS@@`, `@@TOC@@`, `@@BODY@@` |
| `worobin.css`, `worobin.js` | стилі й скрипт сторінки |
| `sections/<id>.html` | розділи; `§ @@N@@` нумерується автоматично; порядок і назви в змісті — `ORDER` у `build.py` |
| `sections/chastyna-N.html` | заставки п'яти частин |
| `norm_names.py` | єдине написання імен і назв; застосовується до всієї сторінки й до перекладів документів |
| `docs_add.py`, `docs_fix.py` | додати або виправити документи в `w18-docs.json` |

Мітки в розділах: `@@DOCS_M@@`, `@@DOCS_S@@` — список документів (з `w18-docs.json`), `@@PEOPLE@@` — список учасників (з `tools/povstantsi/w18-list.html`).

Правила написання: Боковець, Пирішко, Кузин, Димковський, Олексієвець, Пальонка, Рабешко, Велюнець, Харківець; Селець, Острівці. Цитати з преси на `presa.html` не змінюються.
